# Hono / Workers — バックエンドテスト

入口の対応付け、スイート分離、注釈は[共通テスト](common-testing.instructions.md)に従う。ブラウザシナリオには適用しない。

## 既定スイート

| 対象 | テスト境界 |
| --- | --- |
| 純粋な業務関数 | モックなしで同値分割を検証 |
| service | repository / service のポートを注入し、シナリオの結果を検証 |
| Hono の入口 | 宣言済みの機能 route factory を `Request` で実行し、基盤は境界でフェイク |
| メッセージ処理 | フレームを検証し、宣言済みメッセージ処理ポートを永続化 / 配送のフェイクで実行 |

- 動作は固定契約と REQ の分割クラスから導出する。実装が偶然 export したハンドラーを import しない。
- 入口では検証エラー、主体識別 / 認可の拒否、成功時の呼び出し、結果からステータス / レスポンスへの変換を確認する。契約が要求する場合は Origin / CSRF、upgrade の拒否、期限切れ権限、重複リクエストキー、未知の API レスポンスも確認する。
- 純粋な業務関数をモックしない。権限テストは常に成功するフェイクで認可の欠落を隠さず、制御した境界データで実際の方針判断を実行する。
- DB、実ネットワーク、workerd、ブラウザは既定スイートで起動しない。

## ローカルランタイム統合

- Cloudflare 対応の Vitest 統合で workerd とローカルバインディング上で実行する。実行ごとにストレージを分離し、fixture を明示的に投入し、本番識別子に接続しない。
- D1 はクエリ前に実際のマイグレーションファイルを適用し、制約、条件付き更新、batch ロールバック、方言依存 SQL を確認する。
- Durable Objects は名前空間ルーティング、再構築後の永続状態、WebSocket コールバックと attachment の復元、重複排除、再開時の欠落、並行性境界を実行する。生きたインスタンスの再利用だけでハイバネーション / 再起動を網羅したと主張しない。
- R2 は認可済みアクセス、検証 / 確定、欠落オブジェクト、再試行 / 削除を網羅する。事前署名付きブラウザ CORS はローカルでモデル化できなければエンドポイントで個別に検証する。
- Worker / assets の振り分けはローカルプレビューで検証し、API 失敗を HTML SPA 成功にしない。プロトコル確認はブラウザスイートに含めない。
- ローカル確認の成功は本番の上限、デプロイ権限、リモートサービスの可用性を証明しない。実行したランタイムとバインディングを報告する。
