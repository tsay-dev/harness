# 📦 対訳チェックシートの厳格フォーマット（review/script.md）

> 人間チェックの主戦場となる対訳シートの必須フォーマットを定める。
> **訳文とその根拠を隣り合わせ**に並べ、人間の視点移動を最小にする。列は固定。
> なぜこの型か（全行を等しく読ませない）は [overview.md](overview.instructions.md)。訳文の起こし方は [register.md](register.instructions.md)。
> 実行手続きは skill [translate-manga-ko-ja](../skills/translate-manga-ko-ja/SKILL.md) の Stage 3。

## 列（固定）

```markdown
| ID | 原本(韓) | 日本語案 | 話者→聞き手 | 口調/レジスター | 文脈ノート | 信頼度 | 用語 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1-1 | 이보게, 용병. 내 지시를 잊었나? | おい、傭兵。私の指示を忘れたのか？ | 公爵→傭兵C | 하게체/見下し | 高位貴族から格下への冷徹な命令 | ✅ | 既存 |
| 1-2 | ...돈만 주시면 움직입니다. | …金さえくだされば動きます。 | 傭兵C→公爵 | 해요体/割り切り | 敬語だが忠誠心はない態度 | ⚠敬 | 既存 |
```

- **ID**: `<コマ>-<セリフ>` で原本に一意に対応（人間が画像と突き合わせる鍵）。
- **信頼度**: `✅`（確定）／`⚠<理由コード>`（要確認）。理由コードは下記。
- **用語**: `既存`（glossary と一致）／`新規`（master-update.md へ提案済み。[consistency.md](consistency.instructions.md)）。
- **人間の修正**: `日本語案`を直接上書きする（修正履歴は git 差分が保持するので専用の修正欄は設けない）。

## ⚠ の理由コード（人間の注意をここへ誘導する）

| コード | 意味 |
| --- | --- |
| ⚠敬 | 敬語レジスターが曖昧（どの日本語口調か判断が割れる） |
| ⚠慣 | 慣用句・ダジャレ・語呂（意訳の妥当性を要判断） |
| ⚠文 | 文化・歴史依存の含意（背景知識が要る） |
| ⚠名 | 固有名詞の初出（訳語の確定を要判断） |
| ⚠人 | 一人称/二人称の選択（俺/私、お前/あなた 等） |
| ⚠音 | 擬音・擬態語（의성어/의태어。通常セリフと訳し方が違う） |
| ⚠OCR | 原本が不鮮明で読み取りに自信がない |

> AI は「通るはず」と思い込んだ行こそ `⚠` を付ける（[overview.md](overview.instructions.md) チェックコスト最小化）。各レジスター判断の根拠は [register.md](register.instructions.md)。
