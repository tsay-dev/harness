# 📦 crow — コーディング規約（全層共通 / 独自 PHP フレームワーク）

PHP・JS・CSS・HTML・SQL に共通する書式の正本。層固有の差分は [frontend-coding](frontend-coding.instructions.md) と [backend-coding](backend-coding.instructions.md) にあり、共通規約をそこへ複写しない。コメントは日本語で書く。

## 書式

| 対象 | インデント |
| --- | --- |
| PHP / CSS / JS / SQL ファイル / HTML 内の PHP | TAB |
| HTML | 半角スペース 1 個 |

- 文字コードは UTF-8、改行は LF、BOM なし。すべてのファイルは改行で終わる。
- `{` と `}` を縦に揃える（Allman）。`switch` の `case` ブロックはインデントし、`break` は内側・外側どちらでもよい。
- 演算子の前後にスペースを入れる。`else if` を使う（`elseif` ではない）。
- 行幅は半角 80 文字を基準に、式の切れ目か括弧で折り返す。`// ------` の罫線コメントは先頭のインデントを含めて 80 文字に揃える。
- PHP ファイル末尾の閉じタグ `?>` は残す。

## 命名

- php / js / css の識別子は snake_case。
- メソッドの引数は末尾に `_` を付ける（`$arg1_`）。
- リクエストパラメーター由来の値を入れる変数は先頭に `i_` を付ける（`$i_name = crow_request::get("name");`）。内部で生まれた値には付けない。

## 文と式

- 文字列へ変数を直接埋め込まず、`.` で連結する（`"値は、".$value." です"`）。
- 複数行にまたがる文の末尾 `;` は独立した行に置き、直前の行のインデントに揃える。

```php
$sql = model_xxx::sql_select_all()
	->and_where("aa", "bb")
	;
```

- 複数行にまたがる関数呼び出しは `(` と `)` を縦に揃え、引数の区切りは行末のカンマ、入れ子のブロックは改行する。

```php
exec_function
(
	"arg1",
	nested_call
	(
		"arg2",
		12345
	),
	"last"
);
```

- 真偽値と null の比較は常に `===` / `!==`。NOT 演算子 `!` は禁止（`=== false` / `!== true` で書く）。

## コメント

- php / js のコメントは `//<TAB>コメント`。3 行以上は `/* … */`。
- コメントの前に空行を入れる。ブロックを開いた直後の行は不要。
