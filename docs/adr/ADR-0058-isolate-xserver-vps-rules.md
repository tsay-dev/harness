# ADR-0058 Xserver VPS 向け規約を独立した選択パッケージにする

## Context

Xserver VPS 内で動かすプロジェクトに、Hono と React SPA の開発規約が必要になった。API、永続化、配信を VPS 内で完結させる適用範囲を、独立した選択単位として表現する。

## Decision

`rules-xserver-vps-hono-react` を独立して選択できる APM パッケージとする。Hono と React SPA の開発方針と VPS の実行基盤に関する規約をこのパッケージで定義する。個別ホストの接続先、資格情報、リソース識別子は消費プロジェクトが持つ。

パッケージ選択、出力の隔離と再生成の安定性は `tools/apm/test_projection.py` で検査する。運用時の規約適用は文書とレビューによる説得的統制（R-901）であり、パッケージの生成成功だけで VPS の設定や稼働を保証しない。

## Consequences

VPS プロジェクトへ必要な規約だけを導入でき、既存利用者の選択や挙動を変えない。一方、独立したパッケージとして規約と検証を維持する必要がある。実際の VPS の構築・配備は、このルール追加とは別に検証する。

## 却下した選択肢

- **既存パッケージに実行環境の条件分岐を追加する**: 対象外の規約も同時に導入されるため、独立した選択単位を採用する。
