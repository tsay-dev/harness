# ADR-0043 harness のプロンプト正本を日本語に統一する

## Context

harness の会話と docs 成果物は日本語だが、プロンプト正本、ツール README、テンプレートの作成指示には英語を基本とする方針があった。日本語のパッケージもあり、手順や規約を読む際に言語が混在していた。ユーザーは harness 内のすべてのプロンプトを日本語へ変更するよう指示した。

## Decision

skills、rules、agents とその参照資料、リポジトリの作業指示、ツール README、テンプレートの作成指示を日本語へ統一する。パッケージの自然文 description も対象にする。言語方針の正本は `CLAUDE.md` とし、配布先の生成物は中立ソースから生成する。

識別子、パス、コマンド、設定キー、列挙値、`applyTo`、外部 API、契約で固定された見出しや実行例の構文を保持する。翻訳では規約の意味、必須・推奨の強さ、例外、役割、品質ゲートを変更しない。動画制作で生成する画像プロンプトの英語指定や韓国語の翻訳原文など、成果物・サンプルの言語契約は内部指示の言語と区別する。

言語方針自体は文書とレビューによる説得的制御とする。既存の生成検証と参照検証で配布と構文を確認し、独立レビューで翻訳の欠落と意味の変化を確認する。

## Consequences

- 良: 日本語でプロンプトの内容と責任分担を確認し、修正できる。
- 良: skills・rules・agents と関連ガイダンスの言語が揃う。
- 悪: 大量の翻訳差分が生じるため、否定、例外、参照先、固定語彙の保全を確認する必要がある。
- 悪: 英語を基本に読む利用者には扱いにくくなる。日本語化によるトークン量や実行性能の改善は、この変更では保証しない。

## 却下した選択肢

- **英語を基本とする従来方針を維持する**: ユーザーが求めるプロンプト全体の日本語化を満たさないため採用しない。
